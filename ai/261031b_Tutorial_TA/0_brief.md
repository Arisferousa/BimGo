# T-A brief: tutorial and tips

Asked 2026-10-31 (the same user as V-A, P-A, M-A and U-A): a tutorial walkthrough that shows the UI to a first-time
user, in both the full walkthrough and the simple viewer. Ask first whether to skip it; then show each function. The
full one is long, the viewer's short. A button in the menu plays it again and shows the step count. Other features
welcome (ask).

## Decisions (asked and answered)
- **Steps: do it to continue.** Steps that can be tried ask for it (walk, open the menu…) and move on once done; the
  others have NEXT. Every step can be skipped (NEXT / Enter); BACK goes back.
- **Extras chosen:** chapters to pick from (the menu replays one or all), tips the first time a feature is used (can
  be turned off in INTERFACE), and a viewer copy offers its short tutorial the first time it opens on each PC (even
  where the full one was seen). "Remember where I stopped" was offered and not chosen.
